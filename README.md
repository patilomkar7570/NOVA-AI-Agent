# NOVA AI Agent

> **NOVA — Natural-language Operating & Virtual Assistant**

### Alpha 0.1 🚧

NOVA is a local AI agent designed to understand natural-language instructions and interact with the web through a real browser.

Instead of manually performing every step yourself, the goal is to simply tell NOVA what you want and let the agent figure out the actions required to accomplish it.

For example:

> **"Open YouTube, search for MrBeast, and open the first video."**

NOVA can understand the request, create an action plan, interact with the browser, and continue working toward the requested goal.

---

# 🌟 What is NOVA?

NOVA is an experimental **local AI agent** being developed to eventually interact with both the **web and the user's computer**.

The current Alpha 0.1 release is primarily focused on **web/browser automation**.

The long-term goal is much bigger:

> **Tell NOVA what you want. Let NOVA figure out how to do it.**
